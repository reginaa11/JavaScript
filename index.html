Лабораторная работа 4: Асинхронность

Инструкция: Открой консоль разработчика (F12 → Console), чтобы увидеть результаты выполнения заданий.

Задания:

  1. Проверка пароля с коллбэками (ask_password)
  2. Последовательное выполнение асинхронных функций:
    • a. С помощью коллбэков
    • b. С помощью функций-уведомителей
  3. Вычисление F(x) = f1(x) + f2(x) + ... + fn(x) для n = 2, 4, 6
