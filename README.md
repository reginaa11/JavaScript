## Выполненные задания

### Задание 1: Проверка пароля
- Функция `ask_password` проверяет пароль по правилам:
  - В пароле должно быть ровно 3 гласные буквы (a, e, i, o, u, y)
  - Набор согласных должен совпадать с набором согласных в логине
- В случае успеха вызывается `success`, в случае ошибки — `failure`
- Функция `main` выводит результат на экран

### Задание 2: Последовательное выполнение
Исходные асинхронные функции выполняются в случайном порядке.
Нужно сделать так, чтобы они выполнялись строго по порядку:

**Часть a:** Используя вложенные коллбэки
**Часть b:** Используя функции-уведомители (каждая следующая функция вызывается из предыдущей)

### Задание 3: Вычисление суммы асинхронных функций
F(x) = f1(x) + f2(x) + ... + fn(x), где каждая fi(x) асинхронная.
Реализовано для n = 2, 4, 6 с выводом промежуточных результатов.

## Как запустить
1. Открыть `index.html` в браузере
2. Открыть консоль (F12)
3. Результаты появятся автоматически
