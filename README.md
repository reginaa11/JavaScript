## Задание 8: Многошаговая регистрация

### Общая концепция

Реализована страница регистрации с лоадером и 5 экранами:
1. Приветственный экран
2. Шаг 1: Персональные данные
3. Шаг 2: Телефонный номер и код подтверждения
4. Шаг 3: Оплата банковской картой
5. Финальный экран с поздравлением

### Лоадер (loader.css и loader.js)

При открытии страницы отображается анимированная шкала загрузки. Шкала заполняется от 0% до 100% за 2 секунды с помощью функции setInterval. После завершения загрузки лоадер скрывается, а основное содержимое страницы становится видимым.

### Переключение шагов

Все секции изначально имеют класс invisible. При нажатии на кнопки Далее или Назад класс invisible убирается с нужной секции и добавляется обратно на предыдущую. Переключение осуществляется через функцию showSection.

### Индикатор прогресса

На шагах регистрации отображается полоска прогресса:
- Шаг 1: заполнена на 33%
- Шаг 2: заполнена на 66%
- Шаг 3: заполнена на 100%

### Валидация шага 1 (Персональные данные)

Кнопка Далее заблокирована, пока не заполнены все поля. Дополнительно проверяется совпадение пароля и его подтверждения. Поле Страна заполняется динамически через JavaScript из массива стран.

### Валидация шага 2 (Телефонный номер)

После ввода номера телефона и нажатия кнопки Отправить появляется блок для ввода 4-значного кода. Код можно ввести любой 4-значный. После нажатия Проверить кнопка Далее разблокируется.

### Валидация шага 3 (Оплата картой)

Номер карты разбит на 4 поля по 4 цифры. При вводе 4 символов фокус автоматически переходит на следующее поле. Для перехода к финальному экрану необходимо заполнить все 4 поля, указать срок действия, CVV и подтвердить согласие с условиями.

### Финальный экран

После нажатия кнопки Завершить отображается экран с поздравлением об успешной регистрации.
