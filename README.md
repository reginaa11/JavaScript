# Лабораторная работа 5: Promise, async/await

## Выполненные задания

### Задание 1 (1 балл)
Анализ кода с промисом. Вывод: 1 (второй resolve игнорируется).

### Задание 2 (2 балла)
Промисификация функций из лабораторной 4. Функции с колбэками обернуты в промисы и выполняются последовательно.

### Задание 3 (2 балла)
Вычисление F(x) = f1(x) + f2(x) + ... + fn(x) с помощью промисов для n = 2, 4, 6.

### Задание 4 (2 балла)
Промис для сложения чисел с накоплением:
- Каждые 2 секунды происходит сложение
- Всего 5 шагов
- Проверка типов аргументов
- Демонстрация успеха и ошибки

### Задание 5 (3 балла)
Все предыдущие задания переписаны с использованием async/await.

### Задание 6 (2 балла)
Демонстрация вызова async функции из обычной функции с помощью .then().

### Задание 7 (3 балла)
Моделирование собеседования с помощью async/await. Обрабатываются 3 кандидата с разными временами выполнения заданий.
