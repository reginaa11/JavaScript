# Лабораторная работа 2: Функции и массивы

**Дисциплина:** Основы программирования  
**Язык:** JavaScript  
**Файлы:**  
- `app.js` — все решения (15 заданий по функциям, 15 по массивам)  
- `index.html` — запуск скрипта в браузере  

## Запуск
1. Открыть `index.html` в браузере.
2. Открыть консоль разработчика (F12 → Console).
3. Все результаты выводятся в консоль с пояснениями.

## Структура
- Раздел 1: функции (от простой разности до рекурсии)
- Раздел 2: массивы (базовые операции, сортировка, матрицы, объекты)
